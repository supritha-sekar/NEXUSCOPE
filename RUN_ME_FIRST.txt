NEXUSCOPE — ONE CLICK

Requirements (only once):
1. Install Python 3.11+ from python.org
2. Install Node.js LTS from nodejs.org

To run:
1. Double-click START_NEXUSCOPE.bat
2. Wait for the browser to open
3. NEXUSCOPE will be at http://localhost:5173

To stop:
Double-click STOP_NEXUSCOPE.bat

The launcher automatically creates the Python environment and installs the required packages.
Internet is needed the first time for package installation.
