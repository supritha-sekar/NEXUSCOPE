# Reference directions

1. NIST AI Risk Management Framework (AI RMF) — useful for trustworthy, explainable and governable AI design.
2. FEMA National Incident Management System (NIMS) — useful for incident coordination and operational terminology.
3. OASIS Common Alerting Protocol (CAP) — useful for standardised emergency alert concepts.

These references inform the design direction; the prototype is not an official implementation of any of them.
